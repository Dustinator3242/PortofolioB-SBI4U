# Portfolio électronique · Biologie 12e préuniversitaire

Gabarit de portfolio en français : table des matières, lettres d'ouverture et de clôture, cinq unités (scientifique ontarien, article, carrière, carte conceptuelle), carte des thèmes du cours, collage de photos et bibliographie.

Tous les champs en rose sont à remplacer par ton propre contenu.

## Fichiers

- `index.html` : le site complet (HTML, CSS et JavaScript dans un seul fichier)
- `README.md` : ce fichier

## Publier avec GitHub Pages

1. Crée un dépôt public sur GitHub (ex. `portfolio-biologie`).
2. Téléverse `index.html` et `README.md` (**Add file** puis **Upload files**), puis **Commit changes**.
3. Va dans **Settings** puis **Pages**.
4. Choisis **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis **Save**.
5. Après une ou deux minutes, le lien apparaît : `https://TON-NOM-GITHUB.github.io/portfolio-biologie/`

## Modifier le contenu

- Ouvre `index.html` sur GitHub et clique sur le crayon (**Edit**).
- Remplace les passages roses (classe `ph`) par tes textes. Les lettres sont dans `letterOpen()` et `letterClose()`. Les unités sont dans la liste `UNITS`.
- Enregistre avec **Commit changes**. Le site se met à jour en une ou deux minutes.

## À savoir

- Le site est en lecture seule : les boutons de modification et d'ajout de photos sont cachés.
- Pour ajouter des photos, mets les images dans le dépôt et ajoute `<img src="photo.jpg" alt="description">` dans `index.html`.
- Les polices viennent de Google Fonts : il faut une connexion internet.
- Les cartes conceptuelles contiennent des concepts du cours à titre de départ. Modifie-les pour qu'elles reflètent ce que tu as appris.
