# Portfolio électronique · Biologie 12e préuniversitaire

Portfolio de biologie en français : table des matières, lettres d'ouverture et de clôture, cinq unités (scientifique ontarien, article, carrière, carte conceptuelle), carte des thèmes du cours, collage de photos et bibliographie.

Tous les champs en rose sont à remplacer par ton propre contenu.

## Fichiers

- `index.html` : le site complet (HTML, CSS et JavaScript dans un seul fichier)
- `README.md` : ce fichier

## Modifier ta page

1. Ouvre `index.html` en double-cliquant dessus (il s'ouvre dans ton navigateur).
2. Clique sur **Modifier**, puis clique dans un texte pour l'écrire. Tu peux aussi cocher la liste de vérification et ajouter des photos.
3. Tes changements se gardent dans ton navigateur. **Ils ne sont pas encore dans le fichier.**
4. Quand tu as fini, clique sur **Télécharger ma page**. Ça crée un nouveau `index.html` qui contient ton texte et tes photos.
5. Remplace l'ancien `index.html` par ce nouveau fichier (sur ton ordinateur et sur GitHub).

Fais cette étape de téléchargement chaque fois que tu veux garder tes changements. Sinon, ils restent seulement dans ce navigateur.

Sur le site publié, les boutons de modification sont cachés pour les visiteurs. Pour les voir en ligne, ajoute `?edit` à la fin de l'adresse, mais ce que tu écris ne se garde que dans ton navigateur : utilise **Télécharger ma page** et remets le fichier sur GitHub.

## Publier avec GitHub Pages

1. Crée un dépôt public sur GitHub (ex. `portfolio-biologie`).
2. Téléverse `index.html` et `README.md` (**Add file** puis **Upload files**), puis **Commit changes**.
3. Va dans **Settings** puis **Pages**.
4. Choisis **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis **Save**.
5. Après une ou deux minutes, le lien apparaît : `https://TON-NOM-GITHUB.github.io/portfolio-biologie/`

Pour mettre à jour le site : ouvre le dépôt, clique sur `index.html`, puis sur les trois points et **Delete**, ou plus simplement fais **Add file** puis **Upload files** avec le nouveau `index.html` (il remplace l'ancien), puis **Commit changes**.

## À savoir

- Les polices viennent de Google Fonts : il faut une connexion internet.
- Les articles doivent être approuvés par M. Mark.
- Les cartes conceptuelles contiennent des concepts du cours à titre de départ. Elles ne se modifient pas dans la page : change-les dans le code (liste `UNITS`).
- Si tu vides les données du site dans ton navigateur, tes changements non téléchargés disparaissent.
